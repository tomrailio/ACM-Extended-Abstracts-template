### Mitä muuttui käyttöliittymässä? Nyt käyttöliittymä ohjaa käyttäjää **vasemmalta oikealle ja vaiheittain**: **1. Define Task → 2. Add Exemplar → 3. Output Format → 4. Style → 5. Role → 6. Additional Information** Samalla oikealla oleva **Generated Prompt** on jatkuvasti näkyvissä desktopilla. Erityisen hyödyllinen muutos on Output Format -alue: valittua formaattia ei tarvitse enää arvailla, vaan alapuolella näkyy esimerkiksi: **Selected: JSON, PDF, TXT** Lisäksi `Clear` kysyy varmistuksen ennen kuin sisältö poistetaan. Ja tärkeää: **Copy, Clear, Save ja Load -toiminnot ovat edelleen samat neljä JavaScript-funktiota**, eli emme rikkoneet aikaisemmin toimivaa toimintalogiikkaa.
